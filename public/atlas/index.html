The five layers

Five things that are easy to conflate, kept separate: assets, structures, groves, topology, and state. No layer reduces to another — a pool is not a grove, a shape is not a mechanism, a snapshot is not the machine.

Liquidity structures

A 2-token pool, a 3-token pool, and a 4-token pool are mathematically different objects — the Orchard gives each its own name. Every example below is live on Base right now, with its address. Each arity admits different invariants, different swap mathematics, and different failure modes — the names are graph theory, not ornament.

Branch edge

Bij = {ai, aj}

A two-asset market — an ordinary graph edge. The same pair can exist on many venues at once (multiplicity): NUT/WETH grows on three parallel branches.

Live example: NUT/WETH · Uniswap V3 · — pool ↗

Graft hyperedge

Gij = {wNUT, si, sj}

A rooted ternary hyperedge: rootstock plus exactly two scions. Strictly three tokens, strictly wNUT-rooted. The Sunflower Grove's Twin Grafts run 20/40/40.

Live example: gtINF · wNUT/VVV/DIEM · Balancer v3 · 20/40/40 — pool ↗

Whorl hyperedge

Wijkl = {ai, aj, ak, al}

An unrooted multi-asset hyperedge (n≥3), no distinguished rootstock. pNUT — the 4-merous 25/25/25/25 pool that predates grafting — is the Orchard's heirloom Whorl.

Live example: pNUT · NUT/SNUT/cbETH/cbBTC · Balancer V2 · — pool ↗

Grove subgraph

Gi = φ(𝒪t)

Not a pool — a projection. A grove is any economically, functionally, or historically coherent collection of structures. One structure may belong to many groves at once.

Live example: Sunflower Grove — 5 Twin Grafts on one rootstock — docs ↗

Graft anatomy

The propagation metaphor is literal: a scion from one tree joined to the root system of another, sharing liquidity the way grafted plants share water.

How a graft grows

  1. Rootstock (20%) — wNUT sits at the base of every graft, the shared root that connects all six pools of the Sunflower Grove.
  2. Scions (40/40) — two external assets, joined as equals. For gtINF: VVV (Venice) and DIEM (Venice compute).
  3. One invariant — three tokens, one pool, one continuous function. Swaps price all three against each other directly.
  4. Weights are form — 20/40/40 is the Twin form. Future forms (Equal 33/33/33, Rootstock 70/15/15) change the geometry, never the arity.
G = {wNUT 20% · si 40% · sj 40%}  —  symbol grammar: g+t+THEME → gtINF

Grove taxonomy

Four classes by meaning, three practical groves you can walk through today. Grove membership is a function of state — a pool can enter an Arbitrage grove when a discrepancy exists and leave when it's arbitraged away. One pool wears tags from every class at once: gtAGT is Compute crop + Routing guild + Weighted cultivation + Sunflower member.

Canopy forms

Topology is the view from above — the geometric shape the connections make when you squint at the whole system. The Orchard is honest about maturity: parallel markets on the same pair (NUT/WETH on Uniswap V2 and V3) are multiplicity, not Mesh — route redundancy is the seed of Mesh, not its proof. A form is claimed live only when the shape is drawn by real, address-bearing structures.
